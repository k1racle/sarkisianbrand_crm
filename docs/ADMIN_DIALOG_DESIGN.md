# Окна рабочего пространства

Внутренние окна используют явные классы `admin-dialog` и `admin-dialog-backdrop`. Общий стиль задаёт `workspace-dialogs.css`, а завершающий `workspace-typography.css` унифицирует шрифты. Они применяются и к окнам, перенесённым в `body`, но не затрагивают покупательские окна витрины.

- Белая поверхность, нейтральный фон, Montserrat, заголовок 20 px, текст 14 px, вспомогательные подписи 12 px.
- Поля от 44 px, компактные кнопки, радиус 8 px; основное действие тёмное, активная вкладка светло-фиолетовая.
- Боковые редакторы: закреплённые заголовок и действия, прокрутка внутри содержимого, полноэкранный режим на телефоне.
- Заголовки групп полей находятся внутри карточек, а длинные названия переносятся. Чекбокс публикации товара расположен рядом с подписью.
- Общий дизайн распространяется на товары, заказы, категории, промокоды, подарочные карты, бонусный счёт, CRM, поддержку, сотрудников, интеграции, ботов, профиль, медиатеку и поиск разделов.
- Чат: читаемые сообщения, отдельная область каналов, на телефоне переключение между списком каналов и перепиской. Окно создания канала использует тот же дизайн.
- Категория: группы «Основная информация», «Оформление в каталоге», «Публикация»; внутренние отступы, парные поля на ПК и закреплённые действия.
- Баннеры: компактные строки с отдельной первой колонкой перетаскивания, превью, ссылкой, статусом и кнопкой настроек. Поля, расписание, публикация и мобильное изображение открываются только в боковом окне. Черновик изолирован: отмена/ошибка сохранения не меняет список; пустой новый баннер не мешает перетаскивать существующие.

Проверки: `npm run check:workspace-dialogs` и `npm run smoke:workspace-dialogs`. В браузерных проверках приватные чтения заменены фикстурами, записи и внешние запросы запрещены. Это проверка интерфейса, а не реальной отправки сообщений или интеграций.

Для баннеров: `npm run check:banner-editor` (изолированные сохранение/повтор/отмена/блокировка дублирования) и `npm run smoke:banner-editor` (собранный интерфейс, перетаскивание мышью и касанием, вложенная медиатека, четыре ширины).
