# Стандарт интерфейса CRM

Эталон — «Мой день». Область действия: CRM и её телепортированные формы; не витрина и не кабинет клиента.

## Единственный владелец общих элементов

`frontend/assets/css/crm-elements.css`, подключённый первым через `admin.css`. Токены темы — `crm-shell.css`. Классы элементов назначаются в шаблонах; новые экраны не создают собственные варианты кнопок, шрифтов, полей или подложек. Старые CSS-правила общих компонентов вне CRM сохраняются для других интерфейсов. Приоритетный слой CRM защищает элементы от их наследования.

| Элемент | Общий класс / правило |
| --- | --- |
| Страница, заголовок, содержимое | `crm-standard`, `crm-page-header`, `crm-page-content` |
| Кнопка | `crm-button`; основной CTA — `crm-button--primary`; опасное действие — `crm-button--danger` |
| Иконка, текстовая кнопка, строка | модификаторы `--icon`, `--text`, `--row` |
| Поле и поиск | `crm-input`, `crm-input-group` (одна рамка), `crm-check` |
| Переключатель (вместо обычного чекбокса) | Нативный `input[type=checkbox]`: область нажатия 44×44, трек 44×26; строка — `crm-toggle-row`, компактный вариант — `crm-toggle-control` |
| Таблица | `crm-table-head`, `crm-table-row`; кликабельная строка-кнопка обязательно `crm-card-action`, чтобы flex-стиль кнопки не ломал колонки |
| Матрица прав | Нативная таблица `crm-matrix-table` внутри `crm-matrix-scroll`: на всю ширину панели, полные названия ролей с переносом строк, закреплённая колонка разрешений и внутренняя горизонтальная прокрутка; никаких сокращений до «Менеджер» или названий только в tooltip |
| Панель / карточка | `crm-surface`, `crm-item-card`; мягкий акцент — `crm-surface--tint` |
| Фильтры / канбан | `crm-toolbar`, `crm-board`, `crm-board-column` |
| Вкладки карточки | `CrmCardTabs`: отдельная нескрываемая строка под заголовком |
| Карточка задачи / сделки / публикации | `crm-detail-backdrop`, `crm-detail-card`, `crm-detail-body`, `crm-detail-footer`: панель справа на всю высоту, ширина до 720 px (на телефоне весь экран), прокручивается только содержимое; футер не растягивается |
| Подзадачи / комментарии | Общие компоненты `CrmSubtasks` и `CrmCardComments`, одинаковые поля, отступы, пустые состояния и кнопки |
| Заголовок с иконкой | `crm-icon-heading`: flex, выравнивание по центру, иконка 18×18, зазор 8 px; текст внутри `span` |
| Статус | `crm-badge`, семантические токены; всегда есть текст |
| Кликабельная строка | `crm-interactive`, единый hover с карточками и вторичными кнопками |

Montserrat: заголовок 20 px/600, текст и кнопки 14 px/400, подписи 12 px. Обновление — 600 как в эталоне. На телефоне ввод 16 px. Контролы от 44 px, радиус 10 px; панели 16 px, карточки 12 px.

Действия в нижней панели карточки — высотой 44 px, без растягивания по свободной высоте окна. На мобильном основное действие переносится на отдельную строку. Вкладки, подзадачи и комментарии не получают собственных вариантов дизайна на экранах задач и сделок.

Все чекбоксы внутри CRM визуально оформляются переключателями: серый выключенный трек, фиолетовый включённый, белый бегунок. Нативная семантика checkbox, `v-model`, выбор нескольких записей, состояние indeterminate и управление пробелом сохраняются. Radio остаётся radio. Изменения не распространяются на витрину.

Решение от 23.09.2026: боковой редактор «Индивидуальные права» убран со страницы «Роли и права». Проверка фактических прав доступна в строке сотрудника и её контекстном меню, открывается общей боковой карточкой. Ранее записанные разрешения и запреты не удаляются и продолжают учитываться сервером; матрица явно показывает базовые права роли. Отказ от редактора не должен незаметно снимать запреты.

Белые поверхности, холодный фон `#F6F7FB`, фиолетовый `#6658D9`. Обычное наведение — `#F1EEFF`, рамка `#C6BDEE`; основной CTA темнеет до `#5143BC`, текст остаётся белым. Опасное действие сохраняет свой красный смысловой акцент. Бежевые, кремовые и коричневые декоративные подложки запрещены, включая hover, папки, предупреждения и выпадающие меню. Цветовые маркеры этапов остаются данными, не темой всей карточки.

## Проверка изменений

- `node scripts/crm-element-contract.cjs` — применение общих классов к контролам и отсутствие локальных SFC-стилей.
- `node scripts/crm-pages-style-smoke.cjs` — все зарегистрированные страницы на 390/1440 px.
- `node scripts/crm-elements-rendered.cjs` — заполненные карточки, вкладки и формы, размеры и состояния.
- `node scripts/crm-ui-regressions.cjs` — колонки заполненной таблицы, управление переключателем с клавиатуры, кнопки футера 44 px, выравнивание иконок, одинаковые карточки задач/сделок, боковая панель публикации и фильтры воронки.
- `node scripts/crm-operations-rendered.cjs` — сохранение B2B-заказа, отдела и публикации через перехваченные запросы без изменений в реальной базе.
- `node scripts/crm-hover-audit.cjs` — состояния наведения и запрет бежевых поверхностей.
- `node scripts/crm-access-foundation-mock.cjs` — полные названия и ширина матрицы, проверка прав из сотрудников, боковая карточка и архив отделов на 390/1440 px.
- `node scripts/crm-work-smoke.cjs` — перетаскивание, файлы и действия задачи на 360/390/1440 px.

Тесты используют искусственные данные и не изменяют рабочие записи. Скриншоты и вычисленные CSS проверяются дополнительно; статическая проверка классов не заменяет визуальную приёмку.
