# Мини-макет B2B на главной

Правая часть главного блока «SARKISIAN для бизнеса» показывает два пространства кабинета. Страница /business, блогеры, телефон, клуб и остальные блоки не меняются.

- «Мой салон»: две демонстрационные записи, перерыв и пример элемента онлайн-записи.
- «Закупки SARKISIAN»: пример товара с локальным фото, пример цены, счётчик количества 1–9, локальный пересчёт суммы и этапы доставки.
- Графитовая шапка, ровная рамка, спокойная тень; основная панель сохраняет одинаковую высоту при переключении. Переход — только opacity, без наклонов; при reduced-motion выключен.
- Вкладки доступны мышью / касанием / клавишами ← → Home End. Неактивная панель inert, aria-hidden и невидима; её элементы не попадают в фокус.
- Пометка «Пример данных»: записи, цена и сумма не являются действующим расписанием / предложением. Компонент не запрашивает данные клиентов и не создаёт корзины, заказы или записи.

## Редактирование

«Сайт → Контент → Главная → Для бизнеса → Мини-макет кабинета»: подписи вкладок, услуги и подписи записей, перерыв, виджет, товар, фото через существующий медиапикер, пример цены, этапы доставки и пометка демонстрации. Шапка использует прежние «Подпись иллюстрации / Заголовок иллюстрации»; «Строки иллюстрации» используются в виджете и подписи текущего пространства.

Новый опциональный `home.business.preview` имеет строгий ограниченный контракт в API. Старые сохранённые настройки не мигрируются и не перезаписываются: отсутствующие поля получают deep-default на frontend. Сохранение — прежнее явное действие администратора с revision / историей. У рефералов и блогеров поля макета не разрешены.
