# Единый дизайн-код сайта

Область: главная, каталог, товар и рекомендации, информационные и юридические страницы, вход/регистрация, восстановление пароля, избранное, корзина/оформление, кабинет покупателя и все пять боковых панелей. Внутренние рабочие пространства экосистемы имеют отдельный каркас; этот слой не переопределяет их меню или функциональность.

Источники правил:

- `assets/css/typography.css`: локальный Montserrat, размеры и начертания текста.
- `assets/css/storefront-system.css`: семантические цвета, поля, действия, иконки, поверхности, сетка и адаптив. Подключается после прежних CSS, чтобы старые локальные правила не меняли одинаковые элементы.
- `components/storefront/SiteQuantityControl.vue`: один счётчик количества для карточки товара и обеих корзин.
- `components/storefront/SiteSocialLoginButtons.vue`: одинаковые кнопки социального входа в странице и панели.
- `composables/useStorefrontMotion.ts`: общая длительность панелей и reduced-motion.

## Правила элементов

| Роль | Единое правило |
| --- | --- |
| Основной текст | Montserrat, 16 px, 400, межстрочный 1.6 |
| Вторичный текст, название товара в списке | 14 px; служебные метаданные — 12 px |
| Заголовок страницы | общий `--sb-type-page`, 32–48 px, 600 |
| Длинное название товара | 32 px на ПК / 24 px на телефоне, те же семейство и начертание |
| Заголовок секции витрины | общий `--sb-type-section`, крупнее заголовка обычной карточки |
| Заголовок карточки/раздела формы | 24 px |
| Основное действие, в том числе ссылка-кнопка | чёрный фон, белый текст 14 px / 600, минимум 48 px, радиус 14 px |
| Компактное действие | тот же материал/текст, 40 px на ПК / 44 px на телефоне, радиус 12 px |
| Поле формы | 48 px, текст 16 px, радиус 14 px, одинаковый focus |
| Счётчик количества | общий компонент; 48 px в товаре, компактный в списках корзины |
| Карточка/панель | единый стеклянный градиент, рамка, тень, радиус 24 px |
| Обычная иконка Lucide | 20 px, обводка 1.75 |
| Иконка основного действия | 18 px |
| Навигационная иконка | 24 px |
| Иконка пустого состояния | 32 px |
| Социальные логотипы | локальные SVG; вход — красный Яндекс и синий VK, футер и ссылки — монохромные |
| Цвет текста | `--sf-black`; вторичный — `--sf-muted`; на тёмной поверхности — инверсная пара |

Компактные и обычные варианты отличаются размером, а не случайным оформлением. Навигация, вкладки, текстовые ссылки и закрытие панели не превращаются в чёрные кнопки покупки: для каждой роли есть свой единый стиль. Красный оставлен в микро-бейджах, а не в текстах и основных действиях. Цветная бонусная карта и два ранее утверждённых редакционных акцента Georgia на главной — осознанные декоративные исключения.

По отдельному запросу приглашение «Вступить в клуб» в блоке главной использует тот же `--sf-club-material`, что и бонусная карта, включая наведение. Соседняя кнопка «О клубе» — белая с чёрным текстом. Размеры, шрифты, стрелки и радиусы общие; эти модификаторы не меняют остальные кнопки. Приглашение открывает существующую боковую панель сразу в режиме регистрации. Страница `/club` использует CMS-контент, общую сетку и карточки с монохромными Lucide-иконками; иллюстративный баланс подписан как пример. Редактор: админка сайта → «Страницы» → `/club`; порядок/видимость ссылки: «Оформление» → «Меню сайта».

Подпись SARKISIAN CLUB без иконки. На бонусной карте полупрозрачный сине-фиолетовый слой медленно переливается: только transform/opacity, цикл 20 секунд с плавным обратным ходом, текст и геометрия неподвижны. Вне видимой области анимация приостанавливается через IntersectionObserver, `prefers-reduced-motion: reduce` полностью отключает её. Кнопка остаётся статичной.

Сброс фильтров — вторичное действие `sb-primary sb-secondary`: белый фон, чёрный текст и крестик Lucide вместо стрелки; геометрия общая с основными кнопками. В мобильной панели между сбросом и «Показать товары» 12 px. Закрытие панели — общий стеклянный квадрат с крестиком, как у остальных боковых панелей.

На мобильном каталоге кнопка «Фильтры и сортировка» занимает всю ширину внешнего контейнера: текст по центру всей кнопки, иконка у левого края с отступом 12 px. Нижняя навигация: каталог, аккаунт, избранное, корзина, меню. Последняя кнопка меню выделена чёрным фоном с белой иконкой, в том числе в открытом состоянии; подписи остаются только доступными aria-label.

В боковом меню пункты имеют высоту 56 px без дополнительных промежутков; справа стрелки Lucide ArrowRight 18 px, разделители и подчёркивание сохранены. Верхнее меню остаётся без стрелок и иконок.

Карточки товара растягиваются по высоте ряда: изображение сохраняет пропорции, текстовый блок — вертикальный flex, полное название занимает свободную высоту. Цены и мобильные кнопки покупки находятся на одинаковой высоте между соседними карточками без обрезания названий. На ПК покупка по-прежнему появляется поверх фото при наведении/фокусе, на телефоне расположена под ценой. Проверка `npm run smoke:storefront-cards`: каталог, главная и рекомендации на ширинах 360 / 390 / 430 / 760 / 1024 / 1536 px.

Все внешние контейнеры страниц, верхнее меню, баннер, секции главной и футер используют одну ширину: `--sf-container-width`, максимум 1680 px, боковые поля 24 px на ПК / 18 px на телефоне. Вложенные карточки и колонки имеют свой внутренний padding, но не сужают внешний контейнер. Информационная полоса намеренно полноэкранная. Блоки используют общий ритм отступов. Не добавлять новые локальные размеры шрифтов, случайные цвета или скругления для уже существующей роли.

## Проверка

Из `frontend`:

```sh
npm run prebuild
npm run smoke:storefront-design
npm run smoke:storefront
npm run smoke:storefront-product
npm run smoke:storefront-menu
npm run smoke:storefront-checkout
npm run smoke:storefront-club
npm run smoke:storefront-filters
```

Проверка дизайн-кода проходит реальные публичные страницы на ширинах 1536 / 1024 / 390 px, панели, регистрацию и пять разделов кабинета. Сравнивает фактические стили кнопок/полей, шрифты и переполнения. Заполненные персональные представления используют изолированные UI-фикстуры, не меняющие реальные данные: это проверка оформления, не доказательство бизнес-готовности кабинета или оплаты. Реальную покупку в корзину и выбор варианта отдельно проверяет product-smoke с удалением своего тестового элемента.

Снимки и отчёт: `.screenshots/design-system/`. Проверка и утверждение на реальной VPS остаются отдельной задачей приёмки.

Оформление заказа: общий `SiteCheckout`, стили `storefront-checkout.css`, четыре последовательных шага и черновик на 2 часа. Индекс не запрашивается. На первом шаге `SiteCartRecommendations` показывает до 8 доступных товаров по оплаченным продажам за 90 дней, исключая товары корзины, отмены и возвраты. При отсутствии продаж сортировка по новизне. ПВЗ пока указывается как желаемый: реальные тарифы, справочник и платёжный шлюз ещё требуют подключения. Заказ отправляется на подтверждение без списания денег.

У шагов справа стрелки, у последнего — галочка. Покупка в карточках на устройствах с мышью появляется при наведении или клавиатурном фокусе; на touch доступна без наведения.
На телефоне кнопка покупки расположена после цены, а не поверх изображения. Преимущества используют одинаковый отступ 24 px сразу под иконкой без вертикального распределения `space-between`. Подпись бонусного баланса — белый основной текст 16 px. Футер: внутренние поля 32 px на ПК / 20 px на телефоне, колонки распределяются по всей ширине, заголовки сверху; на планшете и телефоне сетка двухколоночная.

Источники локальных логотипов входа: знак Яндекса из SVG официальной документации `https://doc-binary.s3.yandex.net/src/dev/id/logo-oauth-doc-white.svg`; VK — `https://raw.githubusercontent.com/VKCOM/icons/master/packages/icons/src/svg/20/logo_vk_20.svg`. Отдельные файлы `yandex-id.svg` и `vk-id.svg` не меняют монохромные значки футера. Перед production проверить итоговое оформление OAuth-кнопок по требованиям https://yandex.ru/dev/id/doc/ru/codes/buttons-design и VK ID.
