# Портрет основательницы

Ассет: `public/storefront/svetlana-portrait.png`, PNG 1254 × 1254 с настоящим альфа-каналом.

Источник: отдельное студийное фото Светланы из блока о бренде на https://sarkisianbrand.ru/ (https://avatars.mds.yandex.net/get-yastore/21055393/7f654vzrmkz55scrxlh75jnxkkqndjlv/orig). В интерфейсе используется только локальная копия результата, без зависимости от Яндекс Кита.

Обработка: встроенный инструмент imagegen, скилл imagegen, удаление фона. Это обработанная версия исходного фото, не новая фотосессия.

Запрос обработки:

> Use case: background-extraction. Edit target: the supplied standalone studio portrait of a woman in a black jacket and protective black gloves. Remove only the plain gray background to produce a clean cutout on a genuinely transparent PNG background (actual alpha channel). Keep the person in the photograph unchanged: same face, hair, expression, pose, jacket, gloves, hands, proportions, lighting and framing. Preserve the fine hair edges. No retouching, no added objects, no text, no shadows or halos. The final asset is for a website about-the-founder section.
